Weather Starter uses SQLite with WAL mode for fast concurrent reads. The ORM layer is [Drizzle](https://orm.drizzle.team/) with the `sqlite-proxy` adapter, operating on Node's built-in `node:sqlite` module.

## Schema Definition

The schema is defined in `backend/src/schema.ts`:

```typescript
export const locations = sqliteTable(
  'locations',
  {
    id: integer('id').primaryKey({ autoIncrement: true }),
    latitude: real('latitude').notNull(),
    longitude: real('longitude').notNull(),
    createdAt: text('created_at').notNull(),
    // Weather snapshot fields (nullable)
    condition: text('condition'),
    observedAt: text('observed_at'),
    source: text('source'),
    area: text('area'),
    validPeriodText: text('valid_period_text'),
    temperatureC: real('temperature_c'),
    humidityPercent: real('humidity_percent'),
    rainfallMm: real('rainfall_mm'),
    windSpeedKnots: real('wind_speed_knots'),
    windDirectionDegrees: real('wind_direction_degrees'),
    forecastLowC: real('forecast_low_c'),
    forecastHighC: real('forecast_high_c'),
    uvIndex: real('uv_index'),
    psiTwentyFourHourly: real('psi_twenty_four_hourly'),
    pm25OneHourly: real('pm25_one_hourly'),
    airQualityRegion: text('air_quality_region'),
    forecastPeriods: text('forecast_periods', { mode: 'json' }).notNull(),
    dailyForecast: text('daily_forecast', { mode: 'json' }).notNull(),
  },
  (table) => [
    uniqueIndex('locations_latitude_longitude_unique')
      .on(table.latitude, table.longitude),
  ],
);
```

## Indexes

| Index | Columns | Purpose |
|-------|---------|---------|
| Primary key | `id` | Row identity |
| Unique | `(latitude, longitude)` | Prevent duplicates |

## JSON Columns

Two columns store structured JSON data:

### `forecast_periods`

```json
[
  { "label": "Morning", "forecast": "Partly Cloudy" },
  { "label": "Afternoon", "forecast": "Thundery Showers" }
]
```

### `daily_forecast`

```json
[
  {
    "date": "2024-12-02",
    "forecast": "Afternoon Thundery Showers",
    "temperature_low_c": 25,
    "temperature_high_c": 34
  }
]
```

## Migrations

Migrations are generated by Drizzle Kit and stored in `backend/drizzle/`:

```bash
# After changing schema.ts
npm run db:generate

# Apply to the database
npm run db:migrate
```

The database auto-migrates on server startup, so explicit migration is only needed during development to generate the SQL files for version control.

## Database File

- **Path:** `backend/weather.db` (configurable via `DATABASE_PATH` env var)
- **Mode:** WAL (Write-Ahead Logging) for concurrent read performance
- **Gitignored:** Each developer has their own local database
- **Reset:** `npm run reset` clears all data

## Querying Directly

For debugging, you can query the database directly:

```bash
node --experimental-sqlite -e "const { DatabaseSync } = require('node:sqlite'); const db = new DatabaseSync('backend/weather.db'); console.log(JSON.stringify(db.prepare('SELECT * FROM locations').all(), null, 2))"
```
